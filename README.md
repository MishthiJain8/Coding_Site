# 🐧🐰 Sorty & Hoppy's Sorting Garden

A cute beginner-friendly Streamlit website for learning Java sorting algorithms.

## Topics included

- Selection Sort
- Bubble Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Recursive Bubble Sort
- Recursive Insertion Sort
- Arrays basics

Each sorting page has:

- a one-sentence concept
- a tiny step-by-step explanation
- time and space complexity
- an interactive animated array
- a penguin/rabbit visual guide
- Java code
- line-by-line code explanations
- an exam/interview memory tip

## Run on your computer

1. Install Python 3.10+.
2. Open this folder in VS Code.
3. Open a terminal in the folder.
4. Run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Streamlit will open the website in your browser.

## Put on GitHub

Create a new GitHub repository, then upload:

- `app.py`
- `requirements.txt`
- `.streamlit/config.toml`
- `README.md`

## Deploy on Streamlit Community Cloud

1. Push this whole folder to GitHub.
2. Go to Streamlit Community Cloud.
3. Click **Create app**.
4. Select your repository.
5. Main file path: `app.py`
6. Deploy.

No secret keys or API keys are needed.

## Customize

The site is mostly self-contained in `app.py`, so it is easy to edit:
- colors: CSS near the top
- algorithm explanations: `CONCEPTS`
- Java code: `JAVA_CODE`
- code explanations: `LINE_EXPLANATIONS`
- animation snapshots: sorting step functions
